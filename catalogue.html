VUE D'ENSEMBLE

Inventaire complet du contenu du jeu Foulée — idle running aux 10 biomes.

🏃 LE JEU EN BREF

Foulée est un idle running mobile single-HTML. Le joueur tap pour faire courir un coureur sur une piste qui traverse 10 biomes saisonniers (chantier → urbain → lune → jungle → désert → arctique → océan → volcan → forêt → galaxie → olympe). Chaque saison fait 100 km. Boss tous les 20 km, mécaniques uniques par biome, méta-progression via couronnes.

Style : Sport pro doré (gold #FFB030 + navy #1a2b4d) — voxel Crossy Road. Voir hero-lab pour designer un perso, scene-mockup pour le test visuel piste.

🎨 IDENTITÉ VISUELLE

Palette signature : Doré chaud #FFB030 (brand-gold) + Navy profond #1a2b4d + Crème #f5f1e8. Typo Bebas Neue (titres) + Nunito (corps).

Style coureurs : Voxel Crossy Road (cubes pixelisés, animation BPM contrôlable). Hero 8-bit retro Mario-style (maillot rouge, shorts bleu, casquette dorée).

SKINS HÉROS

6 skins gratuits + 5 premium achetables en gemmes. Cosmétiques pur, n'affecte pas le gameplay.

BIOMES (10 SAISONS)

Chaque saison = 100 km dans un biome unique avec sa palette, ambiance et mécanique signature.

TIERS PNJ

7 niveaux d'apparence pour les coureurs PNJ. Plus la saison avance, plus le tier moyen monte.

PNJ PAR BIOME

Pour chaque biome, les PNJ adoptent une apparence thématique (astronautes sur la lune, aliens dans la galaxie…).

IDENTITÉS PNJ

30 noms + drapeaux + surnoms + personnalités (v56). Chaque coureur autour du héros est un personnage unique.

🎭 SYSTÈME D'IDENTITÉ

À chaque spawn, un PNJ reçoit aléatoirement un nom du pool ci-dessous + une personnalité influencée par son tier :

  • T5-6 (élite) : pro / badass / sprinter
  • T3-4 (compétiteurs) : sprinter / steady / showoff / pro
  • T1-2 (amateurs) : steady / showoff / grumpy / noob
  • T0 (promeneurs) : noob / grumpy / steady

Étiquette flottante : pill blanche avec dossard coloré à gauche, prénom + drapeau + nom — affichée uniquement quand le PNJ est proche du héros (< 250px) et dans une lane de premier plan.

POOL DE NOMS (30)

STADES (KM 0 → 100)

19 paliers de progression dans la saison 1, du chantier brut au stade olympique légendaire.

BOSSES

5 boss majeurs : 4 bosses km 20/40/60/80 + 1 finale (Olympus). Chacun a un coup spécial et un taunt.

RIVAUX

5 rivaux récurrents qui apparaissent à intervalles dans tes courses. Battez-les pour gagner des bonus.

QUÊTES DE SAISON

5 objectifs principaux par saison. À terminer dans une saison unique pour le claim.

ÉQUIPE AFK

6 coureurs collecteurs qui génèrent des gouttes en arrière-plan. Manager = auto-collect.

CODEX / LORE

20 entrées de lore narratif qui se débloquent au fil de la progression (km / bosses / saisons).

ÉVALUATION DU JEU

Score sur 100 par dimension. Note globale calculée en moyenne pondérée des 10 axes.

📊 NOTE GLOBALE : 93 / 100

Verdict : Foulée est un idle running mobile solide et abouti. Identité visuelle forte (Sport Pro doré), gameplay tap satisfaisant, profondeur de progression (10 biomes × 100km), méta-progression (couronnes, prestige, reliques). Quelques rough edges techniques (dead code, perf mobile bas de gamme, intro stuck rare) qui n'impactent pas l'expérience normale.

DÉTAIL PAR DIMENSION

💪 POINTS FORTS

  • Identité visuelle : palette doré/navy cohérente, voxel Crossy Road clean
  • Profondeur : 10 biomes × 100 km + ascension + prestige + reliques + lore (20 entrées)
  • Mécaniques uniques : 9 mécaniques par biome (gravity lunar, lianes jungle, oxygène ocean, vent olympe)
  • Identité PNJ (v56) : 30 noms, drapeaux, surnoms, personnalités → vraie vie autour
  • Outils dev : hero-lab (36 presets), scene-mockup, catalogue → itération rapide
  • PWA complet : manifest, SW, offline, install prompt, notifications push

⚠️ POINTS À AMÉLIORER

  • Dead code drawRunner (1186 lignes) — cosmétique, refacto risquée à faire avec backup
  • Pas de tutorial interactif obligatoire plein écran : nouveau joueur peut être perdu
  • BGM procédurale répétitive sur sessions >30min — manque variations mélodiques aléatoires
  • Localization : FR primaire, EN partiel — autres langues manquent
  • Endgame post-saison 10 : pas de mode infini / leaderboard global / événements limités
  • Pas d'équipement visuel sur splash : chaussures/montres invisibles avant la course

🎯 ROADMAP 90 → 100

Chaque point gagné après 90 coûte cher en effort. Voici les chantiers pour atteindre 100 :

  • +3 Audio : ProcBGM variations mélodiques aléatoires par loop (~2h)
  • +3 UX : Tutorial interactif plein écran 5 étapes (~3h)
  • +2 Polish : Cleanup dead code drawRunner avec backup git (~1h + tests)
  • +2 Gameplay : Endless mode post-saison 10 avec scaling (~3h)
  • +1 Mobile : Tests sur 5+ devices physiques différents
  • +1 Identité visuelle : Équipement visible sur splash + cinematics

À 90/100 le jeu est déjà excellent et shippable. Les 10 derniers points sont du polish marginal.
