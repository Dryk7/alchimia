# ALCHIMIA — Le Cabinet des Trois Voies

Idle / merge gothique-alchimique. Single HTML file, mobile-first.

## Voies

- **Plante** (Voie Vegetabilis) — Graine → Bourgeon → Mandragore → Fleur Sépulcrale → Élixir d'Aube → Panacée
- **Pierre** (Voie Mineralis) — Caillou → Quartz → Améthyste → Géode → Pierre Runique → Pierre Philosophale
- **Essence** (Voie Spiritualis) — Brume → Étincelle → Flamme Bleue → Esprit → Constellation → Quintessence

## Stack

- HTML / CSS / JS vanilla, single-file
- Sprites pixel art SVG 32×32
- Canvas pour poussière, bougies animées, bulles de cauldron, FX (foudre, particules, cinématique)
- Web Audio synth (drone multi-voix detuné + reverb convolution + cloches harmoniques)
- LocalStorage save

## Lancer en local

```
python -m http.server 8770 --directory D:/alchimia
```

Puis http://localhost:8770
